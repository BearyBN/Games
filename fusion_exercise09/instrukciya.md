# Exercise 09 — зубчатое кольцо в Fusion 360 (подробно, по кнопкам)

## Размеры с чертежа
| Параметр | Значение |
|---|---|
| Внешний диаметр (по зубьям) | 90 мм |
| Диаметр впадин | 78 мм |
| Отверстие | 50 мм |
| Толщина | 10 мм |
| Ширина зуба | 10 мм |
| Количество зубьев | 16 |

Идея: в одном эскизе рисуем три круга и одну длинную полоску через центр.
Полоска сразу дает два зуба: сверху и снизу. Потом эту пару повторяем по кругу 8 раз,
и получается 16 зубьев. Ничего двигать и вымерять руками не нужно.

---

## Шаг 0. Подготовка
1. Открой Fusion 360.
2. Вверху слева нажми **File** -> **New Design**.
3. Слева в панели **Browser** раскрой строку **Document Settings** (нажми треугольник).
4. Наведи на **Units** -> нажми значок карандаша справа -> выбери **Millimeter** -> **OK**.
5. Сверху проверь, что выбрана вкладка **SOLID**.

## Шаг 1. Создать эскиз
1. На панели сверху нажми **Create Sketch** (первая иконка: карандаш с квадратиком).
2. В центре экрана появятся три цветные плоскости. Нажми на **горизонтальную** (лежит как пол, это плоскость XY).
3. Вид повернется сверху. Теперь ты в режиме эскиза.

## Шаг 2. Нарисовать три круга
Каждый круг рисуется так:
1. Нажми клавишу **C** (или меню **Create** -> **Circle** -> **Center Diameter Circle**).
2. Кликни ровно в **центр координат** (точка, где пересекаются красная и зеленая оси; курсор к ней примагнитится).
3. Отведи мышь в сторону, появится поле для числа. Впиши число и нажми **Enter**.

Нарисуй так три круга:
- **90** (внешний, по зубьям);
- **78** (основа кольца);
- **50** (отверстие).

После каждого круга инструмент остается включенным, можно сразу кликать снова в центр.
Нажми **Esc**, чтобы выйти из инструмента.

## Шаг 3. Нарисовать полоску для зубьев
1. Меню **Create** -> **Rectangle** -> **Center Rectangle**.
2. Кликни в **центр координат**.
3. Появятся два поля. В первое впиши **10**, нажми **Tab**, во второе впиши **100**, нажми **Enter**.
   - Если полоска получилась лежачей (широкая по горизонтали), нажми **Ctrl+Z** и нарисуй снова, поменяв числа местами: 100, Tab, 10. Главное, чтобы узкая сторона была 10, а длинная 100.
4. Нажми **Esc**.
5. Справа вверху нажми зеленую кнопку **Finish Sketch**.

Сейчас на экране: три круга и длинная узкая полоска через центр, которая торчит за большой круг.

## Шаг 4. Выдавить кольцо (без зубьев)
1. Нажми клавишу **E** (или **Create** -> **Extrude**).
2. Кликай мышкой по областям **между кругом 50 и кругом 78**. Полоска делит кольцо на кусочки, поэтому выбери **все** кусочки этого кольца (их 4: два больших слева и справа, два маленьких сверху и снизу внутри полоски). Выбранные области подсвечиваются голубым.
   - Не выбирай середину (круг 50), это отверстие.
   - Не выбирай кусочки между 78 и 90.
3. В окне справа:
   - **Distance**: впиши **10**;
   - **Operation**: **New Body**.
4. Нажми **OK**.

Получилась шайба: снаружи 78, внутри дырка 50, толщина 10.

## Шаг 5. Выдавить два зуба
1. Слева в **Browser** раскрой папку **Sketches** и нажми на **лампочку** рядом с **Sketch1**, чтобы эскиз снова стал виден.
2. Нажми **E**.
3. Выбери **два маленьких кусочка** внутри полоски между кругом 78 и кругом 90: один сверху, один снизу. Сверху у них дуга круга 90, это и есть зубья.
4. В окне справа:
   - **Distance**: **10** (если стрелка смотрит вниз, впиши **-10** или нажми кнопку смены направления, чтобы зубья совпали с шайбой по высоте);
   - **Operation**: **Join**.
5. Нажми **OK**.

Теперь у шайбы 2 зуба друг напротив друга.

## Шаг 6. Размножить зубья по кругу
1. Меню **Create** -> **Pattern** -> **Circular Pattern**.
2. В окне справа:
   - **Pattern Type** (или Object Type): выбери **Features**.
   - **Objects**: внизу экрана на временной шкале (Timeline) нажми на **последний значок Extrude**. Это выдавливание зубьев.
   - **Axis**: нажми на поле, затем слева в **Browser** раскрой **Origin** и нажми на **Z** (или просто кликни по внутренней круглой стенке отверстия).
   - **Type**: **Full**.
   - **Quantity**: **8**.
3. Нажми **OK**.

8 копий по 2 зуба = **16 зубьев**. Модель готова.

## Шаг 7. Спрятать эскиз и проверить размеры
1. В **Browser** -> **Sketches** нажми на лампочку у **Sketch1**, чтобы спрятать линии.
2. Меню **Inspect** -> **Measure** (клавиша **I**):
   - кликни по вершинам двух противоположных зубьев: должно быть **90**;
   - кликни по стенке отверстия: диаметр **50**;
   - кликни по верхней и нижней грани: **10**.

## Шаг 8. Сохранить
1. **Ctrl+S** (или **File** -> **Save**).
2. Впиши имя, например **Exercise09**, и нажми **Save**.
3. Если нужен файл для печати: в **Browser** правой кнопкой по телу (**Bodies** -> **Body1**) -> **Save As Mesh** -> формат **STL** -> **OK**.

---

## Если что-то пошло не так
- **Не могу выбрать область**: убедись, что эскиз виден (лампочка включена).
- **Зубья выросли не туда (над шайбой)**: в Timeline дважды кликни по последнему Extrude и поменяй направление (минус перед 10).
- **Pattern сделал странную фигуру**: проверь, что **Quantity** 8, а не 16, и что выбрана ось **Z**.
- **Промахнулся где-то**: **Ctrl+Z** отменяет последнее действие.
