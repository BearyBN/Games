# Exercise 09 — зубчатое кольцо в Fusion 360

## Размеры с чертежа
| Параметр | Значение |
|---|---|
| Внешний диаметр (по зубьям) | 90 мм |
| Диаметр впадин (основа кольца) | 78 мм |
| Отверстие | 50 мм |
| Толщина | 10 мм |
| Ширина зуба | 10 мм |
| Высота зуба | (90 - 78) / 2 = 6 мм |
| Количество зубьев | 16 |

## Как открыть готовую модель
1. Fusion 360 -> File -> Open -> Open from my computer.
2. Выбрать `exercise09.step`. Модель откроется как твердое тело.

## Как построить самому (пошагово)

### Шаг 1. Эскиз кольца
1. Create -> Create Sketch -> выбрать плоскость XY (горизонтальную).
2. Инструмент Center Diameter Circle (клавиша C).
3. Кликнуть в начало координат, ввести **78** -> Enter.
4. Снова из центра нарисовать круг **50** -> Enter.
5. Finish Sketch.

### Шаг 2. Выдавить кольцо
1. Extrude (клавиша E).
2. Выбрать область между двумя кругами (кольцо, не центр).
3. Distance: **10** мм -> OK.

### Шаг 3. Эскиз одного зуба
1. Create Sketch -> выбрать верхнюю грань кольца.
2. Center Diameter Circle из центра диаметром **90** — сделать его вспомогательным (выделить, клавиша X, станет пунктиром).
3. Нарисовать вертикальную осевую линию из центра вверх (тоже X — вспомогательная).
4. Rectangle -> Center Rectangle: центр на осевой линии, примерно на высоте 39 мм.
   - Ширина **10** мм.
   - Высота примерно **12** мм, так чтобы низ прямоугольника заходил внутрь кольца, а верх выходил за круг 90.
5. Инструмент Trim (T): отрезать верх прямоугольника по кругу 90, чтобы верх зуба стал дугой.
6. Finish Sketch.

### Шаг 4. Выдавить зуб
1. Extrude (E) -> выбрать контур зуба (часть, торчащую за кольцо).
2. Направление — вниз, на **10** мм (или To Object — нижняя грань).
3. Operation: **Join** -> OK.

### Шаг 5. Размножить зуб по кругу
1. Create -> Pattern -> **Circular Pattern**.
2. Pattern Type: **Features**, выбрать операцию Extrude зуба в таймлайне внизу.
3. Axis: ось **Z** (синяя) или цилиндрическая грань отверстия.
4. Quantity: **16**, Type: Full -> OK.

### Шаг 6. Проверка
- Inspect -> Measure: по вершинам зубьев 90, отверстие 50, толщина 10, ширина зуба 10.
- Сохранить: File -> Save.
