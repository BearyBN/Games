# Мультик: «Кофе-брейк» ☕🦉

Короткий (24 с) мультфильм со звуком: зелёный совёнок-полиглот сидит на стуле
и пьёт кофе, потом ему становится нехорошо, он бежит по коридору в туалет и
шумно облегчается. Всё нарисовано кодом — никаких внешних ассетов.

- **Готовое видео:** `duolingo_coffee.mp4` (960×540, 24 fps, H.264 + AAC)
- **Исходник:** `make_video.py`

## Что внутри

| Время | Сцена |
|-------|-------|
| 0–5.5 с | «Кофе-брейк»: совёнок на стуле, пар над кружкой, довольные глотки |
| 5.5–10 с | Живот забурчал: бледнеет, потеет, роняет кружку, «МНЕ СРОЧНО НАДО!» |
| 10–14 с | Забег по коридору мимо дверей, линии скорости, «ХЛОП!» дверью WC |
| 14–22 с | Туалет: тужится, комикс-звуки «ПФФФ! / БУЛЬ-БУЛЬ! / ПЛЮХ!», смыв, облегчение |
| 22–24 с | Титр «КОНЕЦ» |

Персонаж — самостоятельный мультяшный совёнок-пародия, нарисованный
примитивами (эллипсы, полигоны), а не логотип какого-либо бренда.

## Как пересобрать

```bash
pip install pillow numpy imageio-ffmpeg
python3 make_video.py duolingo_coffee.mp4
```

Рендер занимает около 75 секунд.

## Как это устроено

- **Графика** — Pillow, всё рисуется в двойном разрешении (суперсэмплинг ×2)
  и уменьшается до 960×540, отсюда сглаженные края.
- **Персонаж** — функция `render_owl()`: параметры глаз, клюва, крыльев, лап,
  «болезненного» оттенка, вздутия живота, капель пота. Рисуется на отдельном
  прозрачном слое, поэтому его можно поворачивать и масштабировать.
- **Звук** — синтез на numpy: глотки, урчание в животе, звон кружки, топот,
  хлопок двери, комичные «пффф» (пила с вибрато), «плюхи», выдох и смыв.
  Результат пишется в WAV и подмешивается в mp4.
- **Сборка** — кадры пишутся в `ffmpeg` (из пакета `imageio-ffmpeg`) сырым
  RGB-потоком через stdin, звук подаётся вторым входом.
